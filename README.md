# Clean Zip

Create a source-code ZIP from a project folder, excluding dependencies, build output and common binary/media files.

Choose your computer for installation and usage:

| [For Mac](macos/README.md) | [For Windows](windows/README.md) |
| --- | --- |
| Finder → Quick Actions → Clean Zip | File Explorer → right-click → Clean Zip |
| Apple Silicon | Windows 7 and later; x86/x64 |

[Türkçe](README.tr.md)

Source files stay unchanged. The ZIP appears beside the project folder. **`.env` files are included; check for secrets before sharing.**
