# Clean Zip

Proje klasöründen kaynak kod ZIP'i oluşturur; bağımlılıkları, derleme çıktılarını ve yaygın medya/ikili dosyaları dışlar.

Kurulum ve kullanım için bilgisayarını seç:

| [For Mac](macos/README.tr.md) | [For Windows](windows/README.tr.md) |
| --- | --- |
| Finder → Quick Actions → Clean Zip | Dosya Gezgini → sağ tık → Clean Zip |
| Apple Silicon | Windows 7 ve sonrası; x86/x64 |

[English](README.md)

Kaynak dosyalar değişmez. ZIP, proje klasörünün yanında oluşur. **`.env` dosyaları dahil edilir; paylaşmadan önce gizli bilgileri kontrol et.**
